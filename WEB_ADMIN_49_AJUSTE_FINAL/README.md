# Administración n.º 49 — ajuste final

Subir el contenido de esta carpeta al repositorio de GitHub Pages, con index.html en la raíz publicada. No requiere compilación.

Portada, Historia, Servicios, Ubicación y Contacto se muestran completas, sin paginación, en los tamaños de escritorio verificados: 1536×1024, 1440×900 y 1280×800. En ventanas pequeñas y móviles, el documento permite desplazamiento natural para mantener el texto legible y completo.

Premios conserva su galería de 15 diplomas y su navegación. Solo esta página utiliza JavaScript para paginar la galería. Las otras cinco secciones no dependen de JavaScript para mostrar el contenido completo.

No se oculta contenido mediante overflow del documento. Se conservan los textos y las 14 imágenes originales; el logotipo de la esquina del bulevar sigue fuera del encuadre CSS.

Verificado en Chromium. No se afirma validación de Safari. Las fuentes y el logo del encabezado conservan sus dependencias de red.
